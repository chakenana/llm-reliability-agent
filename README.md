# LLM Reliability Agent

This project explores hallucination detection, uncertainty estimation, and large-small model collaboration for research-oriented LLM agents.

## Goals

- Build a research assistant agent for paper reading and experiment planning
- Compare multi-model answers under the same research questions
- Analyze semantic consistency and uncertainty signals
- Detect possible hallucinations in long-form LLM outputs
- Use smaller models or lightweight evaluators to verify large model responses

## Planned Workflow

1. Parse papers, notes, and technical documents
2. Extract research questions, methods, experiments, and limitations
3. Generate multi-model answers for the same query
4. Compare answer consistency and semantic differences
5. Produce structured reports and experiment logs

## Status

Early-stage graduate research prototype.
